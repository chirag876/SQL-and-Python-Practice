# SQL & Python Practice

This folder keeps my coding practice and database practice problems in one place.

## Repository structure

### `Python/`
Contains practice scripts and problem solutions written in Python.

Sub-categories:
- **Basic / Utility problems** (individual `.py` files at `Python/` level)
  - String operations, list operations, sorting/searching, loops, immutability/mutation demos, etc.
- **`Python/Dictionary Questions/`**
  - Dictionary-focused practice problems.
- **`Python/DSA Questions/`**
  - Data Structures & Algorithms practice.
- **`Python/leetcode 75/`**
  - LeetCode 75 (organized by topic; e.g., `Array-String/`).
- **`Python/fastapiprototype/`**
  - A small FastAPI prototype (includes CRUD/database/models/schemas).

### `SQL/`
Contains solved SQL queries (mostly HackerRank-style problems).

Included files:
- `African_cities.sql`
- `Average Population of Each Continent.sql`
- `Draw The Triangle 1.sql`
- `Draw The Triangle 2.sql`
- `New Companies.sql`
- `Ollivander's Inventory.sql`
- `population_census.sql`
- `The Report.sql`
- `Top Competitors.sql`

## How to use

- Open any `.py` file under `Python/` to view and run the script.
- Open any `.sql` file under `SQL/` to review the query.

## Notes

- Many Python scripts print example output directly when run.
- SQL files usually include the problem statement as comments plus a `Solution:` query.
- This repo is **updated regularly** with new practice problems and solutions.
